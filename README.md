# Chakra UI Study Notes

These are my personal study notes from learning and working with Chakra UI. I use this repository to keep the core ideas, practical patterns, and examples I want to revisit in one place.

The notes focus on Chakra UI v3 with React and JavaScript. Examples use JSX and plain JavaScript so they are easy to adapt to a Vite project. They explain how a feature works, when it is useful, and how to put it into a small working interface.

## What I am covering

The chapters move from project setup and basic components through layout, styling, themes, forms, overlays, accessibility, React integration, and testing. They focus on the parts needed to build and maintain accessible interfaces with Chakra UI.

## Chapters

01. [Set up Chakra UI and build a first component](./chapters/01-setup-and-first-component.md)  
   Install Chakra UI v3 in a Vite React project, configure the provider with JavaScript, add generated snippets, and understand the first component.

02. [Component anatomy and composition](./chapters/02-component-anatomy-and-composition.md)  
   Build interfaces from semantic building blocks, understand compound components, slots, children, and when to compose reusable UI.

03. [Style props and conditional styles](./chapters/03-style-props-and-conditional-styles.md)  
   Use Chakra style props, responsive values, conditional variants, recipes, and CSS variables without losing readability.

04. [Layout and responsive design](./chapters/04-layout-and-responsive-design.md)  
   Create page structure with Stack, Flex, Grid, Container, spacing, breakpoints, and mobile-first responsive values.

05. [Theme configuration and design tokens](./chapters/05-theme-configuration-and-design-tokens.md)  
   Configure a Chakra system, define tokens and semantic tokens, and apply a consistent design language.

06. [Recipes and slot recipes](./chapters/06-recipes-and-slot-recipes.md)  
   Create reusable single-part and multi-part component styles, choose variants, and organize a small component system.

07. [Forms, validation, and accessible feedback](./chapters/07-forms-validation-and-accessible-feedback.md)  
   Build controlled and native forms with labels, validation, errors, helper text, and accessible status feedback.

08. [Dialogs, menus, popovers, and overlays](./chapters/08-dialogs-menus-popovers-and-overlays.md)  
   Use overlay components for dialogs, menus, popovers, tooltips, and drawers with correct state and keyboard behavior.

09. [Color mode and appearance](./chapters/09-color-mode-and-appearance.md)  
   Set up color mode, use light and dark values, apply semantic tokens, and prevent visual flashes during startup.

10. [Accessibility and semantic UI](./chapters/10-accessibility-and-semantic-ui.md)  
   Choose semantic elements, manage focus, keyboard interaction, contrast, labels, and assistive-technology feedback.

11. [React state and component integration](./chapters/11-react-state-and-component-integration.md)  
   Connect Chakra components to React state, controlled and uncontrolled patterns, events, and reusable application features.

12. [Performance, server rendering, and project setup](./chapters/12-performance-server-rendering-and-project-setup.md)  
   Organize providers, reduce unnecessary work, understand SSR and hydration considerations, and keep application setup maintainable.

13. [Migration, testing, and troubleshooting](./chapters/13-migration-testing-and-troubleshooting.md)  
   Test component behavior, migrate v2 patterns to v3, diagnose common setup and styling issues, and check a release-ready interface.
